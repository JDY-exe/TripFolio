Sprint overview
Sprint Overview
This sprint will focus on getting up the last of our core features for our app that weren’t developed in sprint 1, for instance getting the ledger and photo album set up. Additionally, we will begin working on polishing the features that we started last sprint such as some of the social aspects. At the end of this sprint we hope that we have a prototype that achieves most of the goals we laid out but will still need fine tuning and polishing that will really make our product stand out which we can implement in sprint 3.


Scrum Master: Bryce Miller
Meeting Plan: Wednesday afternoons/evenings


Risks and challenges
Since our first sprint went so well we have a solid starting point but as we begin to integrate and develop more features we need to make sure that we don’t mess up previous work. We have some test cases that we have developed to hopefully check that we don’t mess up previous work but as we add more and more features especially features that interact with our trip object it becomes increasingly important that we don’t develop anything that sets us backwards. Another challenge that could appear is work we did in sprint 1 was good for getting our tasks in sprint 1 completed but might make future work more complicated and while we believe that our code base is set up in a way that is modular to hopefully reduce this risk it is still important to note that we might not have foreseen challenges we will face in this sprint and might have to redo prior work that we may not have been responsible for.
